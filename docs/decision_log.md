## Отдельная оговорка об источниках

Исходный `BG_2026_stud.pdf` формулирует target как официальный курс USD/RUB Банка России. Для этого проекта команда явно уточнила target на USDRUBF. В отчёте это расхождение необходимо объяснить, а не приписывать PDF цель по фьючерсу. Точные детали биржевого регламента должны подтверждаться официальной документацией/историческими версиями: https://www.moex.com/ru/derivatives/perpetual-futures/USDRUBF
