## Кандидаты новых экспериментов (ещё НЕ выполнены)

**H10: Level vs delta, matched.** На одинаковых `X`, train-окнах, алгоритмах, hyperparameter policy и календарных ключах сравнить прямое `y=C[t+h]` с `y=C[t+h]−C[t]`; оба оценивать как цену `C[t+h]`. Текущие модели **уже используют delta**. В Ridge проверена также `log(C[t+h]/C[t])`; это **не** тест прямого level.

**H11: Относительные рыночные признаки.** Добавить или заменить сырые `Open/High/Low/Close` на lagged returns 1/2/3/7/14 торговых сессий, расстояние до SMA20 в долях, RSI14, ATR14/Close; проверить funding/изменение funding, а Open Interest % — **только при существующем аудированном PIT-источнике**. Сравнить baseline Core v2 vs `Core v2 + relative` vs `Core v2 with relative replacing raw OHLC`. На начало каждого origin брать **только уже известную историю**; rolling вычислять в торговых сессиях, без сжатия отсутствующих календарных дат. Не добавлять весь список сразу без предрегистрации.

**H12 (опционально): DFM/Kalman** как отдельная научная гипотеза по скрытым динамическим факторам (Giannone et al., 2008 — методологический источник, не доказательство выигрыша для USDRUBF). Оценивать только при достаточном времени для качественного walk-forward.

## Обязательные ограничения

- `conditional EOD / pseudo-PIT`, предварительный календарь и `swaprate_current=ASSUMED_AVAILABLE`; не называть verified.
- Созревание direct h-step target к origin обязательно; для всех сравнений идентичные `(origin_date,target_date,h)`.
- 2025 уже многократно использован для исследовательских решений; новая оценка там exploratory. **2026 final test не использовать для отбора признаков/моделей.**
- Не продолжать подбор XGBoost/CatBoost по внешней validation; предыдущие прогнозы и замороженные данные неизменны.
