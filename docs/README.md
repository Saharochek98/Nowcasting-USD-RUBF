# USDRUBF — Day 1 Research Pack

Создано: 2026-11-19. Формат: Markdown (`.md`), удобен для GitHub, VS Code и совместного редактирования.

## Файлы

- `research_charter.md` — задача, роли, гипотезы, критерии успеха.
- `backtest_protocol.md` — правила временной корректности, train/validation/test и метрики.
- `benchmark_spec.md` — точные baseline-модели и формат выходов.
- `hypothesis_register.md` — реестр проверяемых гипотез и рисков.
- `decision_log.md` — согласованные решения и открытые вопросы.

## Как пользоваться

1. Загрузить **все шесть** `.md` файлов в Git-репозиторий проекта, предпочтительно папку `docs/` (кроме `README.md`, который можно оставить в `docs/README.md`). Это каноническое место с историей изменений.
2. Дать команде ссылку на репозиторий/PR; отметить ответственных за вопросы `Q01–Q08`.
3. По желанию приложить файлы в **ChatGPT Project** как справочные материалы для дальнейших чатов. Это не замена Git: изменения в Project и репозитории сами по себе не синхронизируются.
4. До первого сравнения моделей заполнить вопросы Q01–Q03, Q06–Q07. После каждого решения обновить `decision_log.md` и версию зависимых документов.
