# Предложение политики лагов и использования признаков — B2

23.11.2026. Статус: **ожидает review A**. Применимо к текущей панели v2 в режиме
`conditional EOD / pseudo-PIT`. Файл не разрешает запуск модели с новыми входами.
Часы origin, дополнительные лаги, преобразования и allowlist самостоятельно не
утверждены. `backtest_protocol.md`, данные и модели сохранены без изменений.

## Основание и условия

Для выбранного значения `x` и его исторической версии требуется
`available_at(x,vintage)≤forecast_origin(t)`; при неизвестном timestamp явно
сохраняется допущение. Дата наблюдения/действия не подставляется вместо публикации.
Фактический исторический origin остаётся unknown. Лаги ниже взяты из builder,
не из validation RMSE. Финальный test не оценивался.

Группа **A** означает условную допустимость после принятия предположений A,
**B** — дополнительную проверку либо отдельный сценарий чувствительности,
**C** — исключение из предлагаемой основной предварительной модели.
Модельный allowlist в коде не создаётся. Уверенность ниже характеризует
достаточность доступности, а не полезность для прогноза.

| Группа | Исходный столбец / предлагаемый вариант | Текущий лаг | Необходимые условия | Дополнительный лаг | Предварительная модель / уверенность |
|---|---|---|---|---|---|
| A | `open`, `close`, `high`, `low`, `volume` полной свечи t | 0 торговых шагов | Полная свеча получена до origin; исходная метка сохраняется | Число не назначено; частичную свечу исключить | Условно, после review; средняя, timestamp unknown |
| A | `cbr_usdrub_effective` как действующий уровень | Последняя effective_date≤t | Действующий курс опубликован к origin; не подменять завтрашним | Не предлагается; нужна проверка публикаций | Условно; средняя; effective-policy консервативна по дате действия |
| A | `swaprate_prev_session` | 1 торговая метка USDRUBF | Значение непустое, опубликовано к следующему origin, правила/дата понятны | Не назначен; если нет подтверждения — исключить, а не угадывать | Условно; ниже средней по исторической публикации |
| A | `key_rate_pct_effective` как действующий уровень | Последняя дата таблицы≤t | Дата записи действительно соответствует действующему уровню; известен до origin | Не предлагается; решения проверять по dated announcements | Условно; средняя; не announcement-feature |
| A | `spread_close_minus_cbr` | Наследует оба компонента | Разрешены CLOSE и выбранный курс; доступны оба | Самостоятельный лаг не назначен | Условно; не выше уверенности в обоих компонентах |
| B | `ruonia_pct_last_reported` по существующим правилам | DT<t и date(DateUpdate)≤t | Проверить смысл DateUpdate, календарь ЦБ, соблюдение срока и ошибки экспорта | Не назначен; увеличение числа дней не доказывает PIT | Только отдельный согласованный сценарий; средняя по общему регламенту, низкая по record receipt |
| B | `brent_eia_spot_usd_bbl_lag10d` | 10 календарных дней | Исторические release dates/винтажи должны подтвердить выбранное значение | Не назначен; сохранить 10 только как тестируемое допущение | Отдельный сценарий; низкая/средняя, endpoint SLA unknown |
| B | `usdcnh_investing_price_prev_date` | Последняя provider Date<t | Установить тип Price, timezone/cut-off и правила исправлений; проверить raw аномалии | Нельзя обосновать новый численный лаг до уточнения источника | Не передавать в основную модель; сценарий лишь после review; низкая |
| C | `swaprate_current` | 0 торговых шагов | Историческое опубликование значения TRADEDATE=t должно быть подтверждено | Простое назначение лага в B2 не выполняется | Исключён; общая страница «после 18» не подтверждает историю |
| C | `value` | Нет сдвига | Единица/семантика не установлена, ряд постоянно 0 | Не нужен | Исключён из кандидатов как постоянное неопределённое поле |

Все 16 служебных столбцов — `metadata_only`. `swaprate_available_assumed=true`
не меняет группу текущего funding и не является признаком разрешённости PIT.
`close_t` разрешается только как уже известный текущий уровень, будущий CLOSE
не может войти в признаки. Нулевой funding не считать пропуском; пустой funding
не заполнять нулём и не устранять сдвигом к иной торговой дате.

## Что передавать C после решения A

Кандидаты A: `open,close,high,low,volume,cbr_usdrub_effective,
swaprate_prev_session,key_rate_pct_effective,spread_close_minus_cbr`.
Это девять исходных значений. Представление уровней/изменений и их сочетаний
определяет C/A с train-only fit. Полезность не оценивается в B2, корреляция сама
по себе не служит причиной удаления. Никакого OOS-преимущества не заявлено.

RUONIA/Brent/USD-CNH должны иметь отдельные зарегистрированные сценарии,
версии допущений и сопоставимые origin/target keys. Сценарий чувствительности
не превращает unknown в verified. При строгом PIT все условные группы
блокируются до получения необходимых архивов; RW с текущим CLOSE также
остаётся conditional EOD из-за неизвестной исторической доступности свечи.

## Что решает A

1. Принять или отклонить каждое допущение A и включение факторов B в сценарии.
2. Выбрать origin: условный после полной свечи, фиксированный доказанный час
   или фактически зарегистрированная доступность. Поздний origin не расширяет
   старое информационное множество автоматически.
3. Оставить действующий курс ЦБ либо отдельно зарегистрировать already-published
   курс на завтра; аналогично различать ключевую ставку и announced future level.
4. Задать правила пропусков без заполнения target и funding нулями; обучение
   моделей/импутации только на допустимой истории.
5. Утвердить доказательства для текущего funding и дат/винтажей RUONIA/EIA/CNH,
   прежде чем менять лаги или статусы. Положительный возраст не доказательство.
6. Проверить узкое исправление календарного интерфейса builder в B2:
   используется существующее `is_trading_day_expected`; данные календаря не менялись.
