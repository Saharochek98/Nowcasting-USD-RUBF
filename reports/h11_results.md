# H11-REL-01: CatBoost Core v2 с шестью относительными признаками — результаты

Дата: 2026-11-25. Статус: **exploratory validation 2025**. Final test 2026 не загружался. Таргет — дневной `CANDLE_CLOSE` перпетуального фьючерса USDRUBF (не курс ЦБ), прогноз на h = 1…7 торговых сессий; данные `conditional EOD / pseudo-PIT`, `swaprate_current` — `ASSUMED_AVAILABLE`.

Протокол: [configs/h11_catboost_relative_v1.json](../configs/h11_catboost_relative_v1.json) (байт-в-байт копия препрегистрации из `main`, blob `87ae5a7`), кандидаты признаков: [docs/feature_candidates_H11_2026-11-25.md](../docs/feature_candidates_H11_2026-11-25.md). Артефакты: [results/h11_relative_catboost_v1/](../results/h11_relative_catboost_v1/).

## Вывод

**Шесть относительных признаков не улучшили CatBoost Core v2.** На h = 1–3 R1 чуть лучше R0 (RMSE ниже на 0.03–0.3%), на h = 4–7 хуже (на 0.4–1.6%). Ни одно из семи различий не значимо после поправки Холма; наименьший Holm p = 0.23 (h = 7, где R1 хуже, нескорректированный p = 0.033). Ни R0, ни R1 не лучше RW ни на одном горизонте. Решение по H11: **не подтверждена**; добавление признаков в основной набор не рекомендуется.

## Дизайн

| | R0_MATCHED | R1 |
|---|---|---|
| Признаки | Core v2 (10): `open, high, low, close, volume, cbr_usdrub_effective, swaprate_prev_session, swaprate_current, key_rate_pct_effective, spread_close_minus_cbr` | Core v2 + `logret_1, logret_3, logret_7, range_rel, volume_ratio_20, distance_sma20` |
| Таргет | `C[t+h] − C[t]`, прогноз цены `C[t] + ŷ` | то же |
| CatBoost | 100 итераций, lr 0.03, seed 240112; depth 2 (h = 1, 3, 5, 6, 7) или 3 (h = 2, 4), l2 = 30 — ранее выбранные, без новой настройки | то же |
| Обучение | перефит на каждом origin; пары с `s + h ≤ origin` и target ≤ 2025-12-31; позиции 0–18 календаря (2022-04-26…2022-05-26) исключены | то же, train-окна совпадают побайтно |
| Пропуски | медиана по train-строкам на каждом origin; наблюдённые нули фандинга сохраняются | то же |

Признаки считаются по оси торговых сессий; окно включает завершённую свечу t; неполное окно или знаменатель ≤ 0 дают NaN без заполнения будущим. После исключения 19 сессий все шесть признаков в train и на origin полные.

Validation: 254 общих тройки `(origin_date, target_date, horizon)` на каждом h, пропусков прогнозов нет. RW и факт взяты из [results/rw_drift_experiment/common_pairs.csv](../results/rw_drift_experiment/common_pairs.csv) и сверены с `close` на origin и target.

## Важность признаков

Доля шести новых признаков в суммарной `PredictionValuesChange` R1: 61% на h = 1, 41% на h = 2, 9–18% на h = 3…7. Самые важные из новых — `volume_ratio_20` и `logret_7`. Модель активно использует признаки на коротких горизонтах, но это не превращается в значимое снижение ошибки. Данные: [feature_importance_h11.csv](../results/h11_relative_catboost_v1/feature_importance_h11.csv).

## Проверки

Все проверки в [manifest.json](../results/h11_relative_catboost_v1/manifest.json) пройдены:

* повторный прогон CatBoost Core v2 совпал с [results/catboost_core_v2](../results/catboost_core_v2/) с расхождением 0 на всех 1778 прогнозах;
* у R0 и R1 одинаковые ключи прогнозов и обучающие окна (`train_n`, начало/конец, последняя метка);
* все обучающие метки созрели к origin; горизонт равен h шагам торгового календаря;
* ни прогнозы, ни панель не содержат дат 2026 года;
* 540 файлов в `data/`, `configs/`, `docs/`, `reports/`, `results/` не изменились за время прогона;
* повторный запуск даёт побайтно те же прогнозы и метрики.

Тесты: [tests/test_h11_no_leakage.py](../tests/test_h11_no_leakage.py), 13 тестов — формулы и прогрев признаков, инвариантность признаков и прогнозов обеих моделей к изменению будущих цен и фандинга, зрелость меток, совпадение train-окон, импутация только по train, соответствие торговому календарю, идентичность R0 без прогрева существующему CatBoost.

## Ограничения

* **Чувствительность к обучающей выборке.** Одно лишь исключение первых 19 сессий из ~680 сдвинуло прогнозы R0 в среднем на 0.02–0.11 руб. и ухудшило RMSE/RW с 0.996–1.007 до 1.005–1.012. Это сопоставимо с эффектом самих признаков (средний |R1 − R0| 0.02–0.08 руб.). Различия порядка 1% RMSE у CatBoost на этих данных не стоит интерпретировать без статистической проверки.
* 2025 год многократно использован в проекте; результат exploratory. Отсутствие значимости не означает эквивалентности.
* `swaprate_current` в обеих моделях — допущение `ASSUMED_AVAILABLE`, исторический момент публикации не подтверждён.
* Параметры CatBoost подбирались для Core v2 без новых признаков; для R1 они могут быть неоптимальны. Это намеренное ограничение протокола (новый подбор запрещён).
* Расчёт на macOS (Python 3.11.13, catboost 1.2.10), а не на Windows; совпадение с сохранённым прогоном точное.
