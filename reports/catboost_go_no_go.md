# CatBoost после RW with Drift: GO / NO-GO

**Решение: GO на один ограниченный исследовательский пилот. Автоматического запуска нет.**

RW drift не улучшил RW ни на одном h. Сильно регуляризованная Ridge близка к модели с drift; её слабость не доказывает отсутствия нелинейного сигнала. Содержательная гипотеза: связь будущего изменения цены с funding/RU ставкой/отклонением от CBR зависит от порогов и взаимодействий уже существующих Core v2 признаков. Гипотеза может оказаться неверной; в текущих результатах подтверждения ей нет. RUONIA/Brent/USD-CNH в минимальный пилот не включаются.

Команде имеет смысл выделить время на один полный воспроизводимый эксперимент, а не на многократный перебор по 2025 году. Если ресурсов недостаточно для walk-forward, тестов и отчёта, **NO-GO по ресурсам**; запрет на final test сохраняется в любом случае. Временной дедлайн пользователем не задан, поэтому оснований объявлять ресурсный NO-GO сейчас нет.

Следующий этап заранее ограничен [proposal-конфигурацией](../configs/catboost_core_v2_proposal.json):

- Те же 10 признаков Core v2, frozen v2 loader, funding `ASSUMED_AVAILABLE`; без новых признаков/лагов/rolling, PCA и отбора переменных.
- Семь direct-моделей `C[t+h]−C[t]`, expanding/prequential, только targets ≤ origin; train-median imputer переобучается на допустимой истории. Модель возвращает correction, цена восстанавливается прибавлением текущего close.
- Четыре комбинации depth={2,3} и l2_leaf_reg={10,30}; iterations=100, learning_rate=0.03, seed=240112, loss=RMSE, thread_count=1, без outer early stopping. Alpha Ridge не перенастраивается.
- Выбор комбинации по pooled ценовому RMSE на внутренних хронологических origins: два полугодия 2023 и первое полугодие 2024, все inner targets раньше первого внешнего origin. Внутреннее обучение тоже использует только уже созревшие метки; основной validation не применяется для tuning/early stopping.
- Те же 254 target-пары на h, сохранённые RW/AR/RW drift/Ridge для сравнения; RMSE, MAE, bias, RMSE/RW, n и время вычислений. До запуска зафиксировать Holm-семейство CatBoost против RW/drift/Core × семь h (21 тест).
- Обязательные leakage-тесты: инвариантность прошлых прогнозов при изменении будущих X/y, maturity h=1…7, train-only imputer/tuning, сохранение zeros/missing funding, неизменность saved baseline keys и воспроизводимость seed. Затем полный unittest, B3/B4 и отчёт.

Критерий завершения пилота: один отчёт обо всех h и неудачах, без автоматического расширения сетки после просмотра 2025. Любой успех на 2025 остаётся **exploratory** после нескольких итераций и требует независимой заранее согласованной оценки. До такой оценки рекомендация к применению модели не делается.

На данном шаге подготовлены решение и минимальная спецификация; реализация/обучение CatBoost относятся к следующему этапу. Пакет не устанавливался, модели не обучались, final test не использовался.
